# Dashboard M&M's · Diseño Mecatrónico (ESPE)

¿Nos dan los 47,9 g que promete la bolsa? Análisis estadístico de 30 bolsas de M&M's de chocolate (570 chocolates medidos): prueba t, intervalos de confianza, cartas de control I-MR y X̄-S, capacidad Cpk (OIML R 87), ANOVA y correlación.
